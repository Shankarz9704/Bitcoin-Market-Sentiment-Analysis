# 🚀 📊 PROJECT: Bitcoin Market Sentiment Analysis

A complete Data Analytics portfolio project exploring the relationship between Bitcoin prices and market sentiment (Fear & Greed Index).

## 💯 Tools Used

* **Python** (Pandas, NumPy, Matplotlib)
* **SQL** (MySQL / PostgreSQL)
* **Power BI**
* **Excel** (Optional for basic data checks)

---

## 🔹 Project Steps

### 1. Data Collection
We utilize a dataset (`bitcoin_data.csv`) that contains three primary columns:
* **Date**: The historic dates measured.
* **Sentiment**: The market sentiment phase (`Fear`, `Neutral`, or `Greed`).
* **Price**: The closing price of Bitcoin.

*(Note: Data is available in the `bitcoin_data.csv` file generated by `generate_dataset.py`.)*

### 2. Data Loading & Cleaning (Python)
Using `pandas`, we perform the following:
* Load the CSV.
* Remove any missing `NaN` values.
* Drop duplicate rows.
* Parse strings into correct `datetime` objects.

*(See `analysis.py` for full implementation.)*

### 3. Data Preprocessing & EDA
Sentiments are converted into numerical forms for potential modeling or statistical checks (Fear=0, Neutral=1, Greed=2). Then, exploratory data analysis is performed to calculate the average price grouping by sentiment.

### 4. Visualization & SQL Analysis
Data visualizations are rendered directly with `matplotlib` yielding `price_by_sentiment.png` and `price_trend.png`. Detailed business insights are additionally achieved using SQL queries (see `sql_analysis.sql`).

## 🔹 Power BI Dashboard Guide (Step 8)

To recreate the final dashboard in Power BI:
1. **Import Dataset**: "Get Data" > Import `bitcoin_data.csv`.
2. **Line Chart**: 
   * Axis: `Date`
   * Values: `Price` 
   * *Purpose: Shows the Bitcoin Price trend over Date.*
3. **Bar Chart**: 
   * Axis: `Sentiment`
   * Values: `Price (Average)`
   * *Purpose: Plots the Sentiment vs Average Price.*
4. **KPI Cards**: 
   * Calculate Average Price overall.
   * Calculate Max Price overall.

---

## 🔥 Insights (Step 9)

With the generated analysis, the core findings from this dataset include:

* ✔ **Greed Drives Price:** Bitcoin price is consistently higher during periods of `Greed` sentiment.
* ✔ **Fear Triggers Dips:** Price experiences significant drops during `Fear` sentiment periods.
* ✔ **Direct Correlation:** Market sentiment directly impacts and foreshadows major market trends, highlighting why the index is a key tracking metric for traders.
